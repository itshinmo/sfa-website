# RFCs

Proposals with real alternatives. An RFC is not a contract until accepted.

- `active/` — open proposals.
- `archived/` — implemented, rejected, or withdrawn proposals.

Lifecycle: Draft → Proposed → Accepted → Implemented → archived. On ship, fold
current behavior into `docs/`, record an ADR in `decisions/`, cross-link, set
the RFC to Implemented, and move it here.
