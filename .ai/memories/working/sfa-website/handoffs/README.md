# Handoffs

Write one file per agent/task using
[`../../../templates/handoff.md`](../../../templates/handoff.md).

Naming: `<agent>-<task>.md`, e.g. `designer-identity.md`,
`implementer-blog-templates.md`, `quality-auditor-m2.md`.

Each handoff states changed files, verification, open questions, and the next
step. The orchestrator reads these before merging.
